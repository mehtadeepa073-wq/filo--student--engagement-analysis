# Filo Student Engagement Analysis

## Objective
Analyze student engagement and performance data using SQL.

## Tools Used
- MySQL Workbench
- SQL

## Dataset
- 25 Students
- Subject-wise data
- Session attendance
- Average ratings

## SQL Concepts Used
- SELECT
- WHERE
- GROUP BY
- ORDER BY
- COUNT
- AVG

## Key Insights
- Identified top engaged students.
- Calculated subject-wise average ratings.
- Analyzed student participation trends.
